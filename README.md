# Mural Life Competencies

Mural compartilhado para professores registrarem atividades e as Life Competencies trabalhadas.

## Atividades dos alunos (pasta `avaliacao/`)

Autoavaliação e "O que eu sei" sobre Life Competencies, de K4 a Y5.
Link: https://cafra9.github.io/mural-life-competencies/avaliacao/

As respostas são salvas no Supabase pela função `lc-avaliacao-api` (tabela `lc_respostas`).
Salvar é aberto; ler, avaliar e apagar exigem o código do painel da coordenação.
